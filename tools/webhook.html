Discord Webhook Setup

Encodes your webhook so bots that scan GitHub for raw Discord webhook links won't match it. Nothing you paste here is stored or sent anywhere except the optional test message, which goes straight to Discord.

Paste this line into assets/js/config.js
webhook: "",
Install
  1. Open assets/js/config.js in the repository on GitHub and click the pencil icon.
  2. Replace the line webhook: "", with the copied line.
  3. Commit the change. GitHub Pages republishes within a minute or two.
  4. Open the assessment page and confirm the header shows SECURE LINK, not LINK OFFLINE.
